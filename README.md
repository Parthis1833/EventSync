# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/8d6d1a10-06d6-439c-9443-534ac0b77a20

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy [.env.example](.env.example) to `.env` and set `GEMINI_API_KEY` to your Gemini API key. Keep `.env` local; it is ignored by Git.
3. Run the app:
   `npm run dev`
